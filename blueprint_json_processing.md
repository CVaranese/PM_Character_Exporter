This is the important info to be updated, where the entry in the StateAnimations array will contain the relative location of the animation file. As far as I can tell, the 'StateAnimations' array entry does not control fields when pasted, but it does show the names of the animations:

``` json
"StateAnimations",
			"((AirDodge, None),(CeilingBounce, \"/Script/Engine.AnimSequence'/Game/Characters/Workshop/AN_Wrk_Dummy_Idle.AN_Wrk_Dummy_Idle'\")
```

Meaning, for example, StateAnimations[0] = 'Airdodge', StateAnimations[1] = 'Airdodge', = 'Ceiling Bounce', etc.
