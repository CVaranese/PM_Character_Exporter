I need a python program that will convert the below Project M Character data into the below Rivals 2 character data. I did the first one manually to help define the process, but I would like a python script to take the Project M data as input and output the Rivals 2 JSON.

Important things to know about the process:
    - Unit scales are different. For all distance units (radius, offset), Rivals 2 = (10.666) * Project M. These values should be rounded to three decimal points
    - Project M uses bone_index instead of bone names. The mapping is located in ./bones.csv.
    - Sounds are not implemented yet.
    - A knockback conversion calculator is located at ./kb_calc.py
    - AsyncWait and SyncWait contain timing information (measured in frames). This will help you create the proper windows. I am not sure *exactly* how AsyncWait works, since in the example there are two AsyncWait commands at the end that I couldn't figure out how to convert to timing. I manually did the conversion using other sources of information, maybe you can figure it out.
    - Changing 'EnableLandingLag' is what controls the auto cancel window for Rivals 2.
    - The naming of the windows and hitboxes and hitbox on-hit information is not something I created a process for. I am thinking that the hitboxes should be named after the bones that they are set to, with a suffix created if there are multiple hitboxes on the same bone. You can use 'Early' or 'Late' if a hitbox is changed.
        - When CreateHitBox is called on an already existing hitbox_id, it is updated.
    - When manually creating this mapping, i only created four total hitbox on hit properties since two hit boxes shared the same values. You can choose to either simplify them if that is the case or leave it as a 1:1 mapping, it doesn't matter.
